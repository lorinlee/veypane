## 4. Custom Fonts & Binary Assets

- This repository contains **no third-party font files** (`.ttf`, `.otf`, `.woff`, `.woff2`). UI typography uses macOS system fonts at runtime.
- The only binary asset files in this snapshot are the three reproducible icon files generated by `scripts/generate-icon.swift`:
  - `Assets/AppIcon/Veypane-1024.png`

## 5. Browser Extensions (Not Redistributed)

Veypane's macOS 15.4+ extension integration (`ExtensionPackageInstaller` and `ExtensionManager`) enables users to load their own locally obtained unpacked extension directories, `.zip`/`.crx` archives, or already-installed Safari Web Extension `.app`/`.appex` bundles at runtime.

- No third-party extension code, manifests, scripts, stylesheets, or archives are included in this repository.
- Automated tests generate synthetic temporary fixtures on the fly in `FileManager.default.temporaryDirectory`.

## 6. Nominative Interoperability References

Source code contains standard web browser interoperability strings and presets, including:
- Built-in search engine templates (DuckDuckGo, Google, Bing, Brave, Ecosia, Kagi) and optional quick-bookmark URLs in `Sources/VeypaneCore/Models/CoreModels.swift`.
- Standard WebKit/Safari User-Agent preset labels (`Desktop Safari`, `iPhone Safari`, `iPad Safari`) and a lightweight built-in tracker domain filter list in `Sources/VeypaneCore/Rules/ContentRulesEngine.swift`.
- All referenced marks belong to their respective owners and are used solely for identification and interoperability.
